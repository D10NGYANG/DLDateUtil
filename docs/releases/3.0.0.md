## 3.0.0：日期边界修复与 BigInt 接口迁移

本版本集中修复农历、周数、格式化和时间戳边界，并升级构建工具链。由于 npm 时间戳表示和非法输入处理发生变化，以 **3.0.0 主版本**发布。

### 升级前必读

- **JavaScript / TypeScript：** Kotlin `Long` 参数和返回值改为 `bigint`，运行环境必须支持 BigInt；旧 Kotlin Long 对象不可与新包混用。`Int` 仍为 `number`。
- **解析与溢出：** 非法日期、错误分隔符、冲突字段及越界 `Int` 秒数明确抛错，不再静默补值或回绕。负毫秒转换为秒时向下取整。
- **农历范围：** 可空接口返回 null；非空 `lunarCalendar()` 对支持范围外日期抛出明确异常。

完整步骤与示例：[2.3.1 → 3.0.0 升级指南](https://github.com/D10NGYANG/DLDateUtil/blob/3.0.0/docs/migration-3.0.0.md)。

### 主要修复

- 农历正反转换一天偏移、夏令时/历史时区影响、闰月与输入范围校验。
- 节气解码、立春干支年切换、干支日基准。
- ISO 跨年周数，以及月周数在周日提前增加的问题。
- 12 小时制解析崩溃、午夜/正午 AM/PM、重复格式标记及数字截断。
- 历史日期复制、最大年份十二月和毫秒乘法溢出。
- 普通构建不再依赖发布凭据。

### 依赖更新

Gradle **8.14.6**、Kotlin **2.2.21**、AGP **8.10.1**、kotlinx-datetime **0.8.0**、Sonar **7.5.0.8588**、Versions **0.67.0**。npm 发布插件维持 3.5.3；Java 8 目标和 Android minSdk 24 不变。

### 安装

```kotlin

```

Maven 仓库：`https://nexus.bds100.com/repository/maven-releases/`（需访问凭据）。

```sh
npm install dl-date-util@3.0.0
```
